# Fuentes locales

Poné acá `go3v2.ttf` (Gang of Three, Vic Fieger, 2007). El archivo no se versiona porque su licencia de uso web no está confirmada. `css/styles.css` lo carga desde `assets/fonts/go3v2.ttf`; si falta, los títulos usan Archivo.

Gang of Three es la tipografía base del logo (manual de marca, página 13) y en el sitio se usa solo en títulos de sección.
